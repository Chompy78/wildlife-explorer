# Milestone 4.1 Notes

A strict polish and quality release rather than a feature expansion. Replaced raw storage IDs with friendly destination names and icons, added a first-visit Wild Camper introduction, an Expedition Readiness panel, clear selected-state text and clearing for destination previews, live announcements for station and destination changes, and a Photo Wall discovery summary; added responsive and reduced-motion styling. Added a reusable modal-focus hook (focuses the initial control, traps Tab/Shift+Tab, closes on Escape, restores focus after close) and applied it to the Journal, the Wild Camper unlock celebration, and the first-visit Camper Introduction. Save schema moved to version 4, adding `camperIntroductionSeen`; migration preserves Milestone 4 progress and rejects invalid camper-only state when the camper is locked. Added React Testing Library, user-event, jest-dom, and jsdom tests for camper behaviour and modal interaction, and added `scripts/check-encoding.mjs` as ongoing encoding-regression protection.
