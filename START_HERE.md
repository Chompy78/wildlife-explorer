# Start Here

## AI quick summary

Wildlife Explorer is a child-friendly React, TypeScript and Vite wildlife exploration game. This repository is the clean Milestone 5 source baseline.

Tutorial Park is complete. The Wild Camper is playable. The Forest has one arrival location, one short trail, three common animals, photography, Journal integration and return travel to the camper. All other destinations remain preview-only.

## Session start

1. Read `AI.md`.
2. Treat repository files as the source of truth.
3. Run `npm install`.
4. Run `npm run check` before editing.
5. Keep changes within the requested milestone scope.

## Session wrap-up

1. Run `npm run check`.
2. Update current documentation when behaviour or scope changes.
3. Commit source and documentation only.
