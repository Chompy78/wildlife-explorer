# VISUAL_DIRECTION — Wildlife Explorer

## Purpose

This file records the current approved visual direction for **Wildlife Explorer** so future AI/design/coding sessions do not lose the intended look and feel.

## Scope note (added 2026-07-24 — read this before using the file below)

This file is the **art-direction layer**, subordinate to `AI.md`'s Canon and Scope boundary — it does
not override or expand either. Two reconciliations to keep in mind whenever this file drives a Copilot
package or asset brief:

- **"Forest" and "Rainforest" are different things in this repo.** The environment list and confirmation
  image `02_rainforest_many_animals_direction.png` below describe a dense **Rainforest** habitat — but
  `AI.md` lists Rainforest as a **preview-only, not-yet-playable destination**, separate from the
  **Forest** biome (Forest Arrival / Fern Trail) that is actually shipped. Do not use rainforest-dense
  styling as the reference for the shipped Forest screens — doing so would visually imply the Rainforest
  destination is already accessible, which breaks the Scope boundary in spirit.
- **Crystal Cave, Safari, Mountains, Snowlands, Beach/coastal and Wetlands are long-term/aspirational**,
  not current scope. `AI.md`'s Scope boundary blocks "another playable destination... unless a later
  milestone explicitly requires it," and none of these exist in the shipped game yet. Treat everything
  below about them as future-milestone direction to keep on record, not something to brief Copilot on
  today.
- The four "New Confirmation Images" referenced below (`01_tutorial_nature_park_direction.png` etc.)
  are **not present in this repo** — only this markdown description exists. If they're found/recreated
  later, add them under `public/assets/` or a `docs/design-reference/` folder and link them from here.
  Until then, `public/assets/wild-camper/wild-camper-direction.png` (already live in the app) is the one
  concrete image anchor available.

## Current Art Direction Summary

The game should look and feel:

- Cute, but a bit realistic.
- Colourful and nature-focused.
- Friendly for children aged 8 to 14.
- Adventurous, but not scary.
- Rich with plants, animals, water, rocks, trails, and hidden details.
- Polished enough to feel like a real game, not a plain prototype.
- Real-animal focused, with animals behaving naturally.

## Important Visual Rules

### Animals

- Animals should look recognisable and believable.
- Animals should not talk.
- Animals should not wear clothes.
- Animals should not look like pets unless they are actual companion animals, such as the dog companion.
- Wild animals should stay in natural habitats.
- Baby animals can appear, but scenes should stay gentle and safe.

### Characters

- Player characters should look like wildlife explorers, photographers, zoologists, rangers, or researchers.
- Clothing should be practical outdoor clothing.
- The player can be customisable later.
- The visual focus should remain on exploration and animals, not action combat.

### Environments

Environments should be full of discoverable detail:

- Forest paths.
- Rainforest plants.
- Ponds and creeks.
- Safari grasslands.
- Mountain trails.
- Beach/coastal habitats.
- Snowlands.
- Wetlands.
- Secret natural areas.

Each area should feel like a place where animals naturally live.

### Secret Areas

Secret areas are allowed and should feel special, beautiful, and rare.

The key current secret area is:

- **Crystal Cave**

Crystal Cave should feel like a natural wonder rather than a magical creature place.

Current canon says:

- Hidden beautiful places are allowed.
- No magical animals.
- Crystal Cave can have colourful crystals, bats, cave insects, underground water, and rare natural details.

## Things to Avoid

Avoid:

- Dark horror mood.
- Combat poses.
- Weapons.
- Villains.
- Animal cages.
- Captured animals.
- Zoo-like ownership framing.
- Animals wearing clothing.
- Talking animals.
- Overly silly cartoon animals that no longer look like real species.
- Empty flat backgrounds.
- UI-heavy mockups too early.

## Recommended Review Questions for Daughter

Ask these in plain language:

1. Which picture feels most like the game?
2. Which picture looks too busy?
3. Which picture has the best animals?
4. Which picture has the best place to explore?
5. Should the game look more cute, more realistic, or exactly like this?
6. Does the Crystal Cave look exciting or too magical?
7. Should the player character be more visible or should the animals/world be the main focus?

## Current Recommendation

Use this direction as the baseline:

> Bright, colourful, storybook-realistic wildlife adventure art with cute but believable animals, rich natural habitats, hidden details, and a calm exploration feeling.

For Version 1, prioritise:

- clear readable animals,
- beautiful but simple tutorial park environments,
- colourful nature,
- a camera/journal identity,
- and a campervan reward that feels exciting.
